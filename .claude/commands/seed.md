Ripopola il DB demo di Primi Segni:

1. Esegui `npm run seed` (Node 24).
2. Lo script ricrea: una classe, una maestra, ~6 bambini, gli esercizi e i **tentativi storici** con trend in miglioramento (accuratezza ↑, stalli ↓, aiuti ↓), più un bambino con il **cerotto** e uno con l'**alert di blocco**.
3. Conferma il percorso del file DB e un riepilogo delle righe inserite.
